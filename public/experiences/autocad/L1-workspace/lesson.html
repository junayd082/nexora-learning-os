Why it matters

What

The AutoCAD workspace is the screen layout: Ribbon on top, drawing area in the middle, command line below, Model and Layout tabs and the status bar at the bottom.

Why

Every command asks you questions. If you can find the tools and read the command line, you always know what AutoCAD is waiting for.

How

Start commands from the Ribbon or by typing. Read each prompt, choose an option with its capital letter, give input, and check the result.

Common misconceptions

  • Escape deletes work. (It only cancels the current command.)
  • Zooming makes objects smaller. (It only changes the view.)
  • The Ribbon is the only way to run commands.

Questions to ask

  • What is AutoCAD asking you right now?
  • Which drag direction would you use to grab one wall without its neighbors?

Note: Students who finish early: time themselves in Find It mode and try to beat 30 seconds.
